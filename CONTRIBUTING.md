# Contributing

Start with the [development guide](docs/development.md) and
[functional overview](docs/functional-overview.md). Frontend details live in the
[frontend guide](src/MealManager.App/docs/README.md).

Keep changes focused, discuss product changes in an issue, and include the checks
you ran in your pull request. Update the relevant guide when behavior changes.
Run the documented frontend/backend checks for the areas you touch, including
the production browser suite when relevant. Validation runs locally while CI
validation is deferred. Use disposable test data, never household backups
or real credentials.

For security reports, follow [SECURITY.md](SECURITY.md).
